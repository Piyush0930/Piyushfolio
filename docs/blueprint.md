# **App Name**: Piyush Patil Portfolio

## Core Features:

- Hero Section: Hero section showcasing name, title, intro, and social links.
- Skills Showcase: Display skills in a visually appealing grouped layout.
- Project Display: Display projects with images, tech stack tags, and links to GitHub/demo.
- Contact Form: Contact form for sending messages, stored in Firebase Firestore.
- Resume Download: Allow users to download resume.
- Dark/Light Mode Toggle: Enable switching between dark and light modes.
- AI-Enhanced Bio: AI powered tool that personalizes intro/summary, rewriting existing content based on tone adjustments (e.g. casual, professional, friendly).

## Style Guidelines:

- Primary color: Dark grey (#333333) for a professional, sleek look.
- Background color: Very light grey (#f0f0f0) to create a subtle contrast against the content.
- Accent color: Soft blue (#77B5FE) to highlight interactive elements and call-to-actions.
- Body font: 'Inter' (sans-serif) for a clean and modern reading experience.
- Headline font: 'Space Grotesk' (sans-serif) for a futuristic look. 
- Use of minimalistic, line-based icons to represent skills and technologies.
- Grid-based layout to ensure content is well-organized and responsive across devices.
- Subtle fade-in effects for content elements as the user scrolls.
